Installing it

  1. Tap Download above. The file lands in your Downloads.
  2. Open it. Android will say the source is unknown — that is normal for an app that does not come from the Play Store.
  3. Tap Settings on that message, turn on Allow from this source, then go back and tap Install.
  4. It appears as Broll FM with the shelf icon.

Updating? Install the new version straight over the old one. Everything you have already captured stays where it is — do not uninstall first, that would clear it.

On an iPhone

There is no file to install. Open the app in Safari, tap Share, then Add to Home Screen. It behaves the same way and works offline.
